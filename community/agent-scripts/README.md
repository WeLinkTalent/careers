# Community Agent Scripts

Welcome! This is the open space from our blog post
*"Build Your Own AI Agent to Search for Jobs"*.

Share your own job-search agent scripts, prompts and architectures here:

1. Create a folder with your GitHub username: `community/agent-scripts/<your-name>/`
2. Add your script(s), prompt(s) or architecture notes + a short README
3. Open a Pull Request — we'll feature the most effective ones on LinkedIn and the blog.

Also see the [jobs list](../README.md) for current openings.
